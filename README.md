# AI Resume + Job Matching System

An AI-powered web application that helps users upload resumes and compare them with job descriptions.

## Features

* Resume PDF upload
* Skill extraction from resume
* Job match score
* Missing skills suggestions
* Resume improvement tips
* Simple and clean UI

## Tech Stack

* React.js
* Node.js
* Express.js
* MongoDB
* Tailwind CSS
* Axios

## Project Structure

* `client` → Frontend (React)
* `server` → Backend API
* `ai-service` → AI matching logic
* `cloudFiles` → Uploaded resume files

## How to Run

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm start
```
